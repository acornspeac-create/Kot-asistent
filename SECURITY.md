# Security

- Никогда не добавляйте OpenAI API key в Android-приложение или публичный GitHub-репозиторий.
- Храните OPENAI_API_KEY только на доверенном сервере как переменную окружения/secret.
- В продакшене Android-приложение должно обращаться к серверу по HTTPS.
- Если ключ когда-либо попал в публичный доступ, отзовите его и создайте новый.
